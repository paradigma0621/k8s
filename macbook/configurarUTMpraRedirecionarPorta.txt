Onde fica no UTM

VM → Edit → Network

- Se o Network Mode estiver em Shared Network, Bridged ou se a VM usar o backen Port Forward simplesmente não existe.
- Mude Network Mode para Emulated VLAN. Aí surge a aba Port Forward, com a mesma tabela do seu redirecionandoDoVirtualBoxParaSSHinterna.txt:

┌──────────┬───────────────┬────────────┬──────────────┬───────────┐
│ Protocol │ Guest Address │ Guest Port │ Host Address │ Host Port │
├──────────┼───────────────┼────────────┼──────────────┼───────────┤
│ TCP      │ (vazio)       │ 22         │ (vazio)      │ 2222      │

❯ não aparece o "Edit" disponível (fica cinza)

O Edit fica cinza enquanto a VM não está completamente parada. Dois casos:

1. VM rodando. Desliga de dentro do Debian:
sudo poweroff
Fechar a janela da VM não desliga — só esconde.

2. VM suspensa (estado salvo). Esse é o caso que mais pega. Se você em algum moou o estado, a VM fica num limbo: não está rodando, mas o Edit continuabloqueado porque existe um snapshot de RAM que ficaria inválido se você mexesse no hardware virtual.

Na barra lateral do UTM, clique com o botão direito na VM:
- Stop (força a parada), ou
- Delete Saved State / Clear Saved State — dependendo da versão o item tem um desses nomes.

Depois disso o indicador verde ao lado do nome da VM some e aparece o botão ▶ de play. Aí o ícone de Edit (os três controles deslizantes, canto superior direito do painel da VM — atalho
⌘E) fica clicável.

Se mesmo parada continuar cinza, feche o UTM inteiro (⌘Q, não só a janela) e relock de um processo qemu órfão. Dá para conferir no Terminal do Mac:

pgrep -fl qemu

Se listar algo, mate com kill <pid> e reabra o UTM.
